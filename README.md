# Inner Loop - A Minimal Dark Platformer

A simple, atmospheric web-based platformer game built with HTML, CSS, and vanilla JavaScript. Inspired by classic platformers but with a darker, looping theme. All assets are generated programmatically - no external images or sound files are required.

## Theme

You control a simple shape navigating a stark, blocky world. The goal seems to be to reach the exit, but the levels loop, suggesting an inescapable cycle. Unsettling messages occasionally appear, hinting at the character's confusion or the nature of the environment.

## Gameplay

* Navigate minimalistic platforms.
* Avoid hazardous blocks.
* Reach the goal area to proceed.
* Experience the looping nature of the world.

## Controls

* **Move Left:** Left Arrow Key / 'A' Key / On-screen 'Left' button
* **Move Right:** Right Arrow Key / 'D' Key / On-screen 'Right' button
* **Jump:** Up Arrow Key / 'W' Key / Space Bar / On-screen 'Jump' button

## Features

* Minimalist pixel-art aesthetic using simple shapes and a limited color palette.
* Basic platformer physics (gravity, jumping).
* Collision detection.
* Level progression with a looping mechanic.
* Atmospheric text messages.
* Responsive canvas scaling.
* On-screen controls for basic touch/mobile play.
* No external dependencies (runs directly in a browser).

## How to Play Locally

1.  Clone this repository or download the files (`index.html`, `style.css`, `script.js`).
2.  Open the `index.html` file in your web browser.
